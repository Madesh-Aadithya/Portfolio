Step 1 — Create the Project
Goal

Create a clean React project using Vite.

Why Vite?

Vite is fast, modern, and widely used. It gives you:

Fast development server
Hot Module Replacement (instant updates)
Simple configuration
Excellent React support

1. Open your terminal

Navigate to the folder where you want the project.

Example:

cd Documents
2. Create the project

Run:

npm create vite@latest portfolio-ui

It will ask a few questions:

Project name:

Press Enter (or keep portfolio-ui).

Select a framework:

Choose:

React
Select a variant:

Choose:

JavaScript

(We'll use JavaScript first. If you later want to learn TypeScript, we can migrate.)

3. Enter the project folder
cd portfolio-ui
4. Install dependencies
npm install
5. Start the development server
npm run dev

You should see something like:

Local:

http://localhost:5173/

Open that URL in your browser. If everything worked, you'll see the default Vite + React page.


--------------------------------------------------IF USING UBUNTU SERVER------------------------------------------------------

Method 1: SSH Local Port Forwarding (Recommended & Secure)
This forwards traffic from port 5173 on your local computer to port 5173 on your Ubuntu server over a secure SSH connection.

Keep Vite running on your Ubuntu server.

Open a new terminal/command prompt on your local computer (not on the server).

Run the following SSH tunneling command:

Bash
ssh -L 5173:localhost:5173 madesh@<your-server-ip>
(Replace <your-server-ip> with the actual IP address or domain of your Ubuntu server).

Open your local web browser and navigate to:

Plaintext
http://localhost:5173


Method 2: Expose Vite to your Local Network
By default, Vite listens only on localhost inside Ubuntu. It may work through some forwarding, but later we need proper access.

Stop the server:

Ctrl + C

Now start Vite with host enabled:

npm run dev -- --host 0.0.0.0

You should see something like:

Local:   http://localhost:5173/
Network: http://192.168.x.x:5173/

Try opening the Network URL in your Windows browser.

Example:

http://192.168.1.50:5173

Using VS Code SSH Extension?
If you are connected to your server via VS Code Remote - SSH, VS Code usually handles this automatically:

Go to the Ports tab in the bottom panel (next to Terminal / Output).

Look for port 5173. If it's listed, click the globe icon or right-click to select Open in Browser.

If it isn't listed, click Forward a Port and enter 5173.

# Step 2 — Install Tailwind CSS

## Goal

Add Tailwind CSS to our React project.

Why Tailwind?

Instead of writing separate CSS files like:

```css
.card {
  border-radius: 20px;
  background: black;
}
```

we write styles directly:

```jsx
<div className="rounded-xl bg-black">
```

Benefits:

* Faster UI development
* Consistent design
* Responsive classes built in
* Used widely in modern React projects

---

## 2.1 Install Tailwind packages

Inside your `portfolio-ui` folder:

```bash
npm install tailwindcss @tailwindcss/vite
```

---

## 2.2 Configure Vite

Open:

```
vite.config.js
```

You currently have something like:

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

Change it to:

```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
  ],
})
```

---

## 2.3 Add Tailwind to CSS

Open:

```
src/index.css
```

Delete everything inside.

Add:

```css
@import "tailwindcss";
```

---

## 2.4 Test Tailwind

Open:

```
src/App.jsx
```

Replace everything with:

```jsx
function App() {
  return (
    <h1 className="text-5xl font-bold text-blue-500">
      My Portfolio
    </h1>
  )
}

export default App
```

---

## 2.5 Restart Vite

Stop the server:

```
Ctrl + C
```

Start again:

```bash
npm run dev -- --host 0.0.0.0
```

Open the browser.

You should see:

* Large text
* Bold font
* Blue color

---

## 2.6 Save progress

If it works:

```bash
git add .
git commit -m "Setup Tailwind CSS"
git push
```

---

Your first real UI technology is now installed.
